pict-section-fileview

Ten independent pict-section-fileview instances on one page, each pointed at a different file. The viewer detects each type and dispatches to the right lens — text and code and markdown fetch their bytes over a Range request, the image lenses load directly through pict-section-image, and a file no lens can paint degrades honestly to a download card. One orchestrator, a score-tier registry, a child section per kind.
