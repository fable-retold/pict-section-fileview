# Fileview Browser

<!-- docuserve:example-launch:start -->
> **[Launch the live app](examples/fileview%5Fbrowser/index.html)** - runs in your browser, opens in a new tab.
<!-- docuserve:example-launch:end -->


A single pict-section-fileview embedded in an app shell and driven by a file list — clicking a file re-points the viewer, which dispatches to the right lens, reuses the live child on a same-kind re-point, and tears it down on a type switch.
